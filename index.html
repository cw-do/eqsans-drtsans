Call structure

One reduction is two calls. load_all_files() turns events into wavelength histograms; reduce_single_configuration() does everything else.

Things to know before changing the code

Found while reading the source. None of them is obvious from the documentation, and each changes the result.

  1. The order of the pixel corrections is fixed in one place. tof/eqsans/reduction_api.py:44 prepare_data_workspaces: dark → flux → blocked beam → mask → solid angle → sensitivity. tof/eqsans/api.py:1379 prepare_data is a different function with a different order (dark → solid angle → mask → sensitivity → flux) and is not called on the reduce_single_configuration path. To change the order, edit the first one.
  2. Transmission runs get flux normalization and sensitivity only. No dark-current subtraction, no mask, no solid angle (reduction_api.py:164; empty beam at api.py:776). The map shows this as missing stops on the three middle rows.
  3. Several stops do their arithmetic inside Mantid C++. drtsans only builds the arguments: EQSANSCorrectFrame (frame correction), ModeratorTzero (emission time), ConvertUnits/Rebin (wavelength), NormaliseByCurrent (proton charge), SolidAngle, ApplyTransmissionCorrection (angle-dependent transmission), FindCenterOfMassPosition. To change those formulas, look in Mantid, not drtsans.
  4. 2D binning is always unweighted. useErrorWeighting applies to 1D only (iq.py:298 hard-codes bin_2d_method = BinningMethod.NOWEIGHT).
  5. The elastic and incoherent corrections do not touch the errors. After each correction the error array is replaced by the pre-correction one (reduction_api.py:339–356, 392–409, comment EWM-13940). The uncertainties of K(λ) and b(λ) never reach the final I(Q) errors.
  6. There is exactly one output binning. Both corrections bin temporarily to get their factors, apply them to the unbinned points, and the only binning that produces output is bin_all at reduction_api.py:417.
  7. Frame numbering in frame-skipping mode is the reverse of what you would guess. _frame_0 is the skip pulse (long λ) and _frame_1 is the lead pulse (short λ) (tof/eqsans/momentum_transfer.py:301–310). The wavelength gap between the bands is zeroed (correct_frame.py:889–905) and the transmission is fitted per band (tof/eqsans/transmission.py:264–294).
  8. With a single wavelength bin both corrections are skipped automatically (monochromatic mode, correction_api.py:338). The TOF clips are also forced to zero (correct_frame.py:967–973).
  9. Options that are blocked. normalization: "Monitor" raises RuntimeError at api.py:226; absoluteScaleMethod: "direct_beam" raises NotImplementedError at api.py:651; subpixel binning carries a FIXME saying it does not seem to work (api.py:760).
  10. Blocked-beam subtraction works only with "Total charge" normalization. "Time" raises ValueError, "Monitor" warns and skips (blocked_beam.py:48–60).
  11. Stitching is not part of the drtsans reduction. reduce_single_configuration handles one configuration. Joining the 4 m and 8 m curves is done by the eqsanstools wrapper, which calls drtsans.stitch.stitch_profiles (stitch.py:16) itself.
